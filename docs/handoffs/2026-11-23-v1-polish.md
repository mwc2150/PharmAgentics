# v1 polish: approved dots, short questionnaire, feedback spreadsheet, logo, README

Michael asked for five UI fixes for the class demo (2026-11-23). He picked the recommended option for each of four decisions. Claude Opus did items 1, 2 and 4. Two Sonnet agents in worktrees did the questionnaire and spreadsheet (`packet/feedback`, 4146bc0) and the README (`packet/readme`, 1c883c0). Both are merged into `feature/v1-polish` off `main` caada83.

## Decisions (Michael)
1. **Notification dot:** on the "Approved briefings" and Forecast "Approved reports" tabs, and on the sidebar item when that workspace is not open. Rows approved since the last look say "New". "Since the last look" is kept per person and lane in this browser's localStorage. The first visit counts what is already approved as seen. Your own approvals never light the dot.
2. **MLflow link: built, then dropped.** MLflow only runs on the machine running `python -m eval ui`, so a link on the Evaluation page would only ever open for whoever runs it. Michael decided it is not worth showing; the export, API and page are back to main's.
3. **Questionnaire v2:** five optional items: UMUX-Lite (2), traceability, 0-10 recommend, and "one thing you'd change". UMUX-Lite is scored as SUS-equivalent (0.65 × raw + 22.9). v1 responses with SUS scores still load.
4. **Feedback spreadsheet:** `gcp.py feedback` writes `feedback/class-demo-feedback.xlsx` (pseudonymous IDs and role names; free text included). The repo is public, so skim the free text before committing. The tester admin also gets a read-only "Questionnaire responses" panel on the Evaluation page (`GET /api/feedback/responses`, 403 for others).

## What changed
- `frontend/figma-make/src/ApprovedNews.tsx`: the provider sits at the App root. It polls the approved lists every 60 s and when the browser tab becomes visible. `ActiveWorkspace` comes from the Shell. `useApprovedList` reloads a list when its workspace comes into view and marks rows seen only while in view. The Shell keeps hidden workspaces mounted, which first produced a dot with a stale list.
- `forecast_reports.py`: the list carries `reviewed_at`.
- `/api/telemetry/usage` returns `umux`. The usability tiles read UMUX-Lite first.
- Logo: "v1" is gone from the Pa tile and is now small muted text beside "PharmAgentics" in the sidebar (and in the Keycloak header). `favicon.svg/png/ico` now use the same drawing as `pa-mark.svg`, whose letters are about 15% smaller, so the favicon no longer looks chunkier. The PNG and ICO are rendered from the SVG with Playwright Chromium.
- README rewritten for v1, with a "What's new (2026-11-22 to 2026-11-23)" section.
