## Not-scored decision
A not-scored case returns `Feedback(value=None, rationale="Not scored: ...")`. MLflow 3.17.2 (`mlflow/genai/scorers/aggregation.py`, `compute_aggregated_metrics`) skips `None` values ("Exclude None from aggregation"), so `<scorer>/mean` is over scored cases only, and a scorer that scores nothing logs no metric at all. It is not counted as a failed scorer invocation (only `Feedback.error` is). Checked with a three-case experiment in a temp store (scores 0.0, None, 1.0 gave `key_fact_recall/mean` 0.5; an all-None `brief_words` produced no metric). So run.py needs no mean of its own; only the pooled metric is computed there. Consequence: a run whose cases are all unscored has no `key_fact_recall/mean` key (the gate only reads `GATED` keys, so it is unaffected).

- Card matching: when several cards share a territory and direction, the finding takes the card with the most points. `false_drivers` counts a supported driver on a card for a territory with no expected finding as false.
- `brief_words` counts section `text`, card `headline` and `territory_table` cells only, as specified; `kpis` and the table `note` are not counted.
- Cards carry `territory` only after packet E, so `finding_recall` and `false_drivers` are not scored on any run today.
